Infrastructure Layer

Redis 7 (Alpine)
Message broker for Celery tasks + result backend + pub/sub signal channel. Port 6379.
SQLite Database
Embedded ACID-compliant local DB. Stores signals_log, trades, positions, broker_accounts. TRUNCATE journal mode.
ZeroMQ EventBus
Non-blocking PUB socket on port 5557. Broadcasts telemetry, health metrics, and signals to any ZMQ SUB subscribers in real-time.
Docker Compose
4 services: redis, celery-worker, celery-beat, dashboard. All share the same network and SQLite volume.

Data & Strategy Layer

yfinance Provider
Fetches OHLCV candles for BTC-USD, ETH-USD, SOL-USD across 4 timeframes: 15m, 1h, 1d, 1w. Dual-cached: Redis (TTL 5m) + in-memory dict.
Mother Candle Strategy
Identifies mother candle + inside bar breakout patterns on weekly/daily timeframes with multi-timeframe confluence scoring.
Combined Portfolio Strategy
Ensemble strategy combining RSI, Bollinger Bands, MACD, and volume analysis. Generates long/short signals with confidence scores.
Signal Safety Gate
Only signals with confidence ≥ threshold and non-HOLD type pass through to execution. HOLD signals are logged only, never routed.

Broker & Safety Layer

Paper Broker (Default)
Simulates order execution with virtual $100 balance. Tracks positions, unrealized PnL, stop-loss/take-profit, and trade history. Zero capital risk.
Delta Exchange Client
HMAC-SHA256 signed REST calls to Delta Exchange India API. Only activates when mode = LIVE and ExecutionManager is explicitly ARMED.
Dual-Key Arming Gate
Live trading requires: (1) valid API credentials, (2) explicit mode switch to REAL, (3) ARM confirmation phrase. Prevents accidental live orders.
Delta WebSocket
Persistent WSS connection to wss://socket.india.delta.exchange for real-time mark_price, orders, and positions feed with auto-reconnect.

ZeroMQ — Why 0 Packets?

ZeroMQ is a per-process in-memory pub/sub bus. Each Docker container runs its own ZMQ instance. The Celery Worker container publishes telemetry packets there, but that counter is local to the worker process — not shared with the Dashboard container.

The Dashboard's own health monitor thread also publishes to ZMQ (port 5557), so the packet count here reflects dashboard-side telemetry broadcasts only. It increments on every health poll cycle (~every 2–5 seconds).

Key Architectural Notes
  • → HOLD signals are never logged to signals_log or routed to any broker. Only BUY/SELL are actionable.
  • → Redis dual-purpose: Celery task broker and price data cache and pub/sub event channel.
  • → All timestamps are stored in UTC, displayed in Indian Standard Time (IST, UTC+5:30) with 12-hour AM/PM format.
  • → Docker containers share a bind-mounted volume for the SQLite .db file — all containers read/write the same data file.
